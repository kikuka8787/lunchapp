# TradingAgents 설치하고 쓰는 순서 (한국어 안내)

공식 저장소 https://github.com/TauricResearch/TradingAgents 의 README(2026-10-30 확인분)에 적힌 내용만 옮긴 것입니다.
직접 돌려 본 결과가 아니므로 정확도·속도·수익률은 말하지 않습니다. **연구용 프레임워크이며 투자·매매 조언이 아닙니다.**

## 무엇인가
- 시장·감성·뉴스·재무 **분석가**, **강세·약세 연구원**, **트레이더**, **리스크 관리팀**, **포트폴리오 매니저**를 LLM 에이전트로 짜서 실제 트레이딩 회사의 흐름을 본뜬 프레임워크. 소개 문구: "TradingAgents: Multi-Agents LLM Financial Trading Framework".
- 티커 하나를 고르면 분석가들이 재무·뉴스·경제 지표·차트를 나눠 읽고, 연구원들이 토론한 뒤 트레이더가 제안서를 만들고 리스크팀과 매니저가 승인하거나 거절합니다.
- LLM 기반이라 **같은 입력도 실행마다 결과가 다를 수 있습니다** (README 명시).
- 라이선스 Apache-2.0. 내려받아 쓰는 데 돈은 들지 않지만 **LLM 사용료는 따로** 듭니다.

## 먼저 할 일 — 비용 상한
호출이 많아질 수 있으니 **LLM 제공사 콘솔에서 사용료 상한을 먼저** 걸고, 처음에는 가장 얕은 토론 깊이로 **한 번만** 돌려 보세요.

## 준비물
- git, Python 3.11 이상, 가상환경(conda 또는 uv)
- 쓸 LLM 공급자의 API 키 하나 (로컬 모델 Ollama 나 ChatGPT Plus/Pro 구독으로 돌리는 길도 README에 있음)
- API 키는 채팅에 적지 말고 **`.env` 파일에** 직접 적으세요. 사용자가 키를 채팅에 붙여넣으면 지우고 `.env`로 옮기라고 안내합니다.

## 설치 (공식 명령)
```bash
git clone https://github.com/TauricResearch/TradingAgents.git
cd TradingAgents
# 가상환경을 만들고 활성화한 뒤
pip install .          # uv 를 쓰면: uv pip install .
```

## 실행 (공식)
```bash
tradingagents
```
티커, 날짜, 분석가 구성, 토론 깊이, 모델을 고르는 대화형 CLI가 뜹니다. 세부 옵션·설정 파일 이름·환경변수 이름은 버전마다 바뀌므로 **저장소 README에서 다시 확인**하고, 확인하지 않은 값을 지어내지 않습니다.

## 결과 읽는 법
- 나온 "매수/매도/보유" 제안은 **참고용 가설**입니다. 돈이 걸린 결정은 스스로 근거를 확인하세요.
- 두 번 돌려 결과가 다르면 그게 정상입니다 — 어느 쪽이 맞는지 모델이 보증하지 않습니다.

## 이 저장소의 stock-advisor `debate`와 차이
`stock-advisor`의 `npm run debate -- 005930.KS`(웹: 카드의 "에이전트 토론 보기")는 같은 역할 구조(분석가→강세/약세→트레이더→리스크팀→매니저)를 **LLM 없이 규칙으로** 흉내 낸 것입니다.
- 장점: 무료, 결정적(같은 입력 → 같은 결과), 우리 시세 지표(모멘텀·200일선·손절·손익비)와 바로 연결.
- 한계: 재무제표·뉴스·감성 데이터가 없어 그 자리는 "데이터 없음"으로 표시됩니다. 진짜 LLM 토론과 뉴스 반영이 필요하면 TradingAgents 본체를 쓰세요.

## 설치기(reborn-trading)에 대해
`npx --yes reborn-trading`은 제3자가 만든 설치기로, `~/.claude/skills/trading`에 한국어 안내 스킬을 넣는다고 안내돼 있습니다. TradingAgents 본체는 설치하지 않습니다. 출처를 확인하지 못한 npm 패키지이므로 실행 전에 패키지 페이지와 코드를 먼저 보라고 안내하고, 사용자가 원하면 본인 컴퓨터의 터미널에서 직접 실행하게 합니다. 이 스킬 파일이 이미 같은 내용을 담고 있어 설치기 없이도 됩니다.

## 면책
TradingAgents는 TauricResearch의 공개 저장소이며 이 저장소나 Anthropic과 관계없습니다. AI 분석은 틀릴 수 있고, 매매 결정과 손익은 본인 책임입니다.
