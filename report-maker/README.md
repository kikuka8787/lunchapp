# 학교평가 보고서 메이커 (Gemini Canvas 앱)

2026 경기 학교평가 안내서(일반학교 초등 지표 13개)와 학교평가 보고서 틀(예시)을 바탕으로,
지표별 실적·메모를 넣으면 AI가 보고서 문장을 쓰고 한글(.hwpx) 파일로 내려받는 앱입니다.

## 캔버스에 올리는 법
1. Gemini → 도구 → Canvas를 켭니다.
2. `index.html` 내용을 통째로 붙여 넣고 "이 코드 그대로 실행해 줘"라고 요청합니다.
3. 오른쪽 미리보기에서 바로 쓰고, 공유 버튼으로 링크를 나눌 수 있습니다.
   (Canvas 안에서는 API 키가 자동으로 연결되므로 키 입력이 필요 없습니다.)

## 보고서 구성 (보고서 틀 예시와 같은 순서)
- Ⅰ. 학교 현황 — 기본현황 표, 학교 비전 및 교육 목표
- Ⅱ. 평가지표 — 영역·지표·배점 표 + 자체 점수
- Ⅲ. 평가지표별 평가 결과 — 지표마다 지표 정보 표, 평가 척도(선택), 정량 결과 표, 정성(계획 수립 / 운영 내용 / 성과 분석 및 환류)
- Ⅳ. 향후 추진 계획 — 지표별 표

## 주요 기능
- 정량 지표: 숫자(A, B)나 체크만 하면 비율·등급·점수 자동 계산 (1-1, 1-4, 3-1, 3-2, 4-1, 4-2)
- 정성 지표: 평가 주안점을 보며 자체 등급 선택 → 예상 점수
- 메모 → AI 초안(개조식, 메모에 없는 수치·행사명은 ○○로 비움), 지표별 "다시 쓰기", 되돌리기
- 한글(.hwpx) 저장, 글 전체 복사, 작업 백업 파일 저장/불러오기 (입력 내용은 기기에만 저장)

## 참고
- 2-2(진로교육), 3-1 정성은 안내서에 등급별 점수가 없어 배점 비율(100·80·60·40·20%)로 환산한 참고 점수입니다.
- `형식확인용_예시보고서.hwpx`는 시험용 가짜 문장으로 만든 파일로, 한글에서 서식이 어떻게 보이는지 확인하는 용도입니다.
