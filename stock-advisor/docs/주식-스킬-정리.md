## 2. 앱 안의 스킬 (기능)

### 2-1. 추천 종목 분석 — `npm run dry-run` · 웹 "추천 종목 분석"
- 후보: `universe.json`의 한국 50 + 미국 50 대형주(섹터 태그) ∪ `config.json` 관심 종목. 시장 탭(전체/한국/미국)으로 나눠 봄.
- 결과: 시장 국면 → 🏆 추천 TOP N(기본 3) → 📋 내 관심 종목 신호.
- 종목마다: 액션(🟢 매수 관심 · 🟡 매수 대기 · 🔵 보유 · ⚪ 관망 · 🔴 매도 검토), 제안 비중, 항목별 체크(절대 모멘텀·200일선·52주 고점 대비·변동성·거래량·단기 타이밍), 한 문단 근거, 🛡 손절 기준가.
- 카톡 메시지 미리보기 + 복사 버튼 (PlayMCP 연결 전까지는 복사해서 나와의 채팅방에 붙여넣기).

### 2-2. 전략 (듀얼 모멘텀 v2) — `src/strategy.js`
1. **시장 국면**: KOSPI(`^KS11`) / S&P500(`^GSPC`)이 12개월 수익률 > 0 이고 200일선 위 → 상승 추세. 아니면 비중 × `regimeWeight`(0.5).
2. **절대 모멘텀**: 종목 12개월 수익률(최근 1개월 제외) > 0 **그리고** 가격 > 200일선 → 후보. 아니면 관망(현금).
3. **상대 모멘텀**: 3·6·12개월 평균 수익률 ÷ 변동성(위험조정)으로 순위, 상위 `topN`, 섹터당 `maxPerSector`(2).
4. **비중**: `targetVol`(15%) ÷ 60일 실현 변동성, 상한 `maxWeight`(40%), 합계 100% 이내. 추천 종목에만.
5. **단기 타이밍**: RSI 70↑ 과열·MACD 데드크로스 등 점수화 → 추천 후보인데 음수면 "매수 대기", −3 이하면 "매도 검토".
6. **손절**: 최근 60일 고점 대비 월간 변동성 2배(8~20%) 또는 200일선 중 높은 쪽.
7. **방향(bias)**: 20EMA 위 · RSI 50 이상 · MACD 위 셋 다면 상승, 셋 다 반대면 하락, 섞이면 중립 (모닝 브리핑용).

파라미터는 `config.json` → `strategy`, 웹 ⚙️에서 조정.

### 2-3. 백테스트 — `npm run backtest -- --market kr --range 5y` · 웹 "백테스트"
- 월 1회(21거래일) 리밸런싱, 추천 종목만 보유, 현금 수익 0, 편도 거래비용 0.1%, 지수 국면 필터 적용.
- 출력: 총수익·CAGR·최대낙폭·변동성·샤프 (전략 vs 균등 보유), 수익곡선 차트, 최근 리밸런싱 보유 종목.
- 한계: 슬리피지·세금·배당 미반영, 리밸런싱 사이 비중 변동 무시, 생존편향(현재 유니버스로 과거를 봄). **데모 시세 결과는 의미 없음.**

### 2-4. 개장 알림 — `npm run schedule` (옵션 `-- --dry-run`, `-- --brief`, `OFFSET_MIN=10`)
- 🇰🇷 한국장 09:00 KST에는 `.KS/.KQ` 종목만, 🇺🇸 미국장 09:30 ET(지금은 23:30 KST)에는 나머지만. 주말 건너뜀, 서머타임 자동.
- 공휴일은 반영하지 않음(휴장일에도 메시지 나감). `npm run next`로 다음 알림 시각 확인.

### 2-5. 모닝 브리핑 — `npm run brief` · 웹 "메시지 형식: 모닝 브리핑"
(트레이딩뷰 MCP 잭슨의 `morning_brief` 개념)
- 관심 종목마다 **방향**(▲상승/▼하락/■중립 + 기준), **지지/저항**(20EMA·200일선·손절가 / 60일·52주 고점), **볼 것**(RSI 과열·과매도 근접, MACD 크로스 임박, 200일선 테스트, 52주 신고가 도전, 손절 근접, 거래량 급증).
- 끝에 🛡 위험 규칙(`config.json` → `rules.riskRules`).

### 2-6. 세션 저장 · 어제와 비교 — 자동
(잭슨의 `session_save` / `session_get`)
- 분석할 때마다 `data/sessions.json`(웹은 localStorage)에 날짜별 신호 저장. 같은 날 한국장/미국장을 따로 돌려도 하루 한 세션으로 합침.
- 브리핑과 웹에 🔁 **어제 대비**: 액션·방향이 바뀐 종목부터, 추천 진입/이탈. 처음 며칠은 "비교할 세션 없음"이 정상.

### 2-7. 매매 기록 — `npm run trade -- add buy 005930.KS 70000 --qty 10 --stop 64000 --reason "200일선 돌파"` · 웹 "매매 기록"
(트레이딩 스킬 `trader-memory-core`)
- 산 이유·가격·손절가·수량 + 당시 신호를 `data/trades.json`에 기록. `trade list`, `trade remove <id>`.

### 2-8. 신호 복기 — `npm run review` · 웹 "복기 실행"
(트레이딩 스킬 `signal-postmortem`)
- 5일·20일 전 세션의 **모든 신호**를 지금 가격으로 채점: 맞음 / 틀림 / 놓침 / 시장과 엇갈림(시장 탓) / 보합.
- 적중률, 추천·매수 계열·관망 계열 평균 수익률. 우리 전략이 실전에서 맞는지 검증하는 장치 — 2~3주 쌓인 뒤 결과를 보고 전략 조정.

### 2-9. 매매 코칭 — `npm run coach` · 웹 "코칭 받기"
(트레이딩 스킬 `trade-performance-coach`)
- 점검: 손절가 없이 진입 · 손절 폭 과다(20%↑) · 한 종목 비중 초과(`rules.capital` 있을 때) · 신호 역행 매수(관망·매도 검토 종목) · 약세장 매수 · 손절 미이행 · 진입 근거 미기록.
- 반복 실수(2회↑)를 찾아 **다음 매매 규칙** 제안 + 스스로에게 물어볼 질문. 받아들일지는 본인이.

### 2-10. 에이전트 토론 — `npm run debate -- 005930.KS` · 웹 카드 "🏛 에이전트 토론 보기"
(TradingAgents 구조를 LLM 없이 규칙으로)
- 📊 분석가(기술적·리스크·시장 국면; 재무/뉴스는 "데이터 없음" 명시) → 🐂 강세 / 🐻 약세 근거 → 💼 트레이더 제안(진입 방식·비중·손절·1차 목표·손익비·보유 규칙) → 🛡 리스크팀(포트폴리오 최대 손실·손익비·변동성·과열·섹터 집중 → 승인/조건부/거절) → 🧑‍💼 매니저 결론.

### 2-11. 카카오톡 전송 (PlayMCP) — `npm start` ⏸
- 환경변수 `PLAYMCP_TOKEN`(필수), `PLAYMCP_URL`(기본 `https://playmcp.kakao.com/mcp`), `PLAYMCP_TOOL`(전송 도구 이름; 비우면 "나와의 채팅" 설명으로 자동 선택). `npm run tools`로 도구 목록 확인.
- **막힌 이유**: PlayMCP는 Claude/ChatGPT 같은 AI 클라이언트에 붙이는 용도로 안내돼 있고, 직접 만든 앱이 쓸 토큰 발급 방식을 공식 문서로 확인하지 못함. 토큰 얻는 방법을 알려주면 바로 연결.

- [ ] **실제 시세 검증** — 이 클라우드 환경은 Yahoo·네이버 등 시세 사이트가 네트워크 정책으로 막혀 데모로만 검증. 로컬에서 `npm run check` → 실패 종목 코드 수정 → `npm run dry-run`.
- [ ] **PlayMCP 토큰** — 발급 방식 확인되면 `PLAYMCP_TOKEN` 설정 후 `npm run tools` → `npm start`.
